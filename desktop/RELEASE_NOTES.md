# Созвон для ПК 1.4.0

## Курсор в играх во время трансляции
- **Своя программа захвата экрана.** Встроенный захват Chromium на Windows 11 работает только через
  Windows Graphics Capture, и Windows при этом переводит курсор в программный режим: в играх со своим
  курсором (Noita и др.) он пропадал. Теперь экран снимается через DXGI Desktop Duplication, как в OBS:
  системный курсор не трогается, в трансляцию он дорисовывается отдельно.
- Пока трансляцию никто не смотрит, захват стоит на паузе и не тратит ресурсы.
- Если что-то не работает: трей → «Совместимый захват экрана» (прежний захват Chromium).

## 1.3.0

## Игры и трансляции
- **Курсор в играх больше не должен пропадать.** Раньше приложение постоянно держало системный перехват
  клавиатуры и мыши (ради горячих клавиш), и каждое движение мыши в игре шло через него. Теперь:
  - «Выключить микрофон / звук» — через обычную регистрацию сочетаний Windows, без перехвата;
  - перехват включается только для рации и только пока вы в голосовом канале (только клавиатура
    нужна, но системная библиотека ставит и мышь — поэтому в играх лучше режим «по голосу»).
- **Захват экрана** по умолчанию через Desktop Duplication, а не Windows Graphics Capture (у него бывает
  пропадающий курсор в играх). Вернуть — в трее «Захват экрана: Windows Graphics Capture».
- **Трансляция кодируется видеокартой (H.264)** — меньше нагрузка на процессор у стримера.

## Прочее
- Фото и видео из чата открываются внутри приложения (просмотрщик со стрелками и зумом), а не в браузере.

- Свёрнутое или перекрытое окно больше не рисуется (раньше видео и анимации обрабатывались и в фоне).
  Звук, рация и уведомления работают как прежде.

  трансляция — в 2 с лишним раза меньше (замер на двух участниках).

## Трансляции
- Чужая трансляция открывается кнопкой «Смотреть трансляцию», закрывается — «Выйти из трансляции».
  Пока вы не смотрите, видео к вам не идёт.
- На своей трансляции — кнопка «Остановить демонстрацию».

## 1.1.0

## Новое
- **Автообновление.** Приложение само проверяет обновления на вашем сервере (каждые 2 часа и при запуске),
  скачивает новую версию в фоне и ставит её при выходе — или сразу, по кнопке «Перезапустить и обновить»
  в трее. Если приложение свёрнуто в трей и вы не в голосовом канале, обновление ставится само и
  приложение возвращается в трей. Обновления идут с вашего сервера, доступ к GitHub не нужен.
- Работает в установленной версии для Windows и в AppImage для Linux. Портативный zip показывает
  уведомление со ссылкой на скачивание.

## 1.0.0

Первая версия отдельного приложения «Созвон» для Windows и Linux.

## Что умеет
- **Глобальная рация:** клавиша «нажми и говори» работает в играх и других программах. Сочетания
  «выключить микрофон» и «выключить звук» тоже работают глобально.
- **Трей:** при закрытии окна приложение сворачивается в трей, из меню трея можно выключить микрофон или звук,
  выбрать «Сервер…», включить автозапуск или выйти.
- **Автозапуск** при входе в систему (по желанию), запуск сразу свёрнутым в трей.
- **Демонстрация экрана** с выбором экрана или окна по превью. На Windows передаётся звук компьютера.
- **Уведомления Windows** и счётчик непрочитанных на значке в панели задач.
- Свой сервер: адрес задаётся при первом запуске и меняется в «Сервер…». Самодельный сертификат принимается
  только после явного согласия и только для этого адреса.
- Ссылки на другие сайты открываются в обычном браузере. Микрофон и камера доступны только своему серверу.
- Приложение запоминает размер и положение окна. Вторая копия не запускается, вместо этого открывается уже запущенное окно.
- Проверяет, нет ли новой версии на сервере, и предлагает её скачать.

## Важно
- У приложения нет цифровой подписи, поэтому Windows SmartScreen предупредит при первом запуске:
  нажмите **«Подробнее» → «Выполнить в любом случае»**.
- Версии для macOS нет, на Mac пользуйтесь браузером.
- На Linux глобальная рация работает только в сеансе X11.
