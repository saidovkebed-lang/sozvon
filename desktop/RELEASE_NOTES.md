# Созвон для ПК 1.0.0

Первая версия отдельного приложения «Созвон» для Windows и Linux.

## Что умеет
- **Глобальная рация:** клавиша «нажми и говори» работает в играх и других программах. Сочетания
  «выключить микрофон» и «выключить звук» тоже работают глобально.
- **Трей:** при закрытии окна приложение сворачивается в трей, из меню трея можно выключить микрофон или звук,
  выбрать «Сервер…», включить автозапуск или выйти.
- **Автозапуск** при входе в систему (по желанию), запуск сразу свёрнутым в трей.
- **Демонстрация экрана** с выбором экрана или окна по превью. На Windows передаётся звук компьютера.
- **Уведомления Windows** и счётчик непрочитанных на значке в панели задач.
- Свой сервер: адрес задаётся при первом запуске и меняется в «Сервер…». Самодельный сертификат принимается
  только после явного согласия и только для этого адреса.
- Ссылки на другие сайты открываются в обычном браузере. Микрофон и камера доступны только своему серверу.
- Приложение запоминает размер и положение окна. Вторая копия не запускается, вместо этого открывается уже запущенное окно.
- Проверяет, нет ли новой версии на сервере, и предлагает её скачать.

| Файл | Платформа |

| `Sozvon-1.0.0-x86_64.AppImage` | Linux x64 |
| `SHA256SUMS.txt` | контрольные суммы |

## Важно
- У приложения нет цифровой подписи, поэтому Windows SmartScreen предупредит при первом запуске:
  нажмите **«Подробнее» → «Выполнить в любом случае»**.
- Версии для macOS нет, на Mac пользуйтесь браузером.
- На Linux глобальная рация работает только в сеансе X11.
