# Astra 2.0 — дизайн-система «Космос»

Короткая шпаргалка: из чего собран внешний вид, где что лежит и какие правила держать,
чтобы новое выглядело как часть Astra и не тормозило.

## Файлы

| Что | Где |
| --- | --- |
| Токены (цвета, радиусы, тени, типографика, движение) | `public/css/tokens.css` |
| Базовые стили компонентов | `public/css/app.css` (+ `watch.css`) |
| Слой Astra 2.0: фон, стекло, движение, профили 2.0, темы серверов | `public/css/astra2.css` (подключается последним) |
| Живой фон: когда двигаться, когда замереть | `public/js/ui/cosmos.js` |
| Темы серверов (применение + раздел «Оформление») | `public/js/ui/server-theme.js` |
| Рамки, баннеры, значки (клиент) | `public/js/ui/cosmetics.js` |
| Переход при смене канала | `public/js/ui/motion.js` |
| Списки и валидация на сервере | `server/cosmetics.js` |
| Плитки звёзд (генератор) | `tools/gen-cosmos.mjs` → `public/assets/cosmos/*.svg` |
| Рамки аватаров | `public/assets/frames/*.svg` |
| Иконки значков | `public/assets/astra-ui.svg` (спрайт) |

Шрифты внешние не грузим: Inter, если установлен, иначе системный стек — без сдвига вёрстки
и без запросов в интернет (Astra часто работает в локальной сети).

## Цвет

Тёмная тема по умолчанию — «Космос»: глубокий синий с фиолетовым, как ночное небо вокруг знака-«иглы».

- Фоны `--bg-0…5` — от «космоса» (`#070817`) к поднятым поверхностям; `--bg-elevated` — модалки и поповеры.
- Текст: `--text`, `--text-muted`, `--text-faint` (≥ 4.5:1 на `--bg-2`), `--text-message`.
- Акцент `--accent` (#6a45ff) и производные: `-hover`, `-active`, `-text` (акцент как текст), `-soft`,
  `-soft-strong`, `-glow`, `-gradient`. Для кнопок с акцентным фоном текст — `--text-on-accent`.
- Космос: `--star` (тёплая звезда), `--star-cool`, `--nebula-1…3` (туманности).
- Оболочка поверх неба: `--shell-rail`, `--shell-side`, `--shell-main`, `--shell-header`, `--shell-panel` —
  полупрозрачные в тёмной теме, непрозрачные в светлой и AMOLED.
- Светлая тема (`data-theme="light"`) и AMOLED (`data-theme="amoled"`) переопределяют те же токены.
  В светлой теме звёзд нет; в AMOLED панели чисто-чёрные, звёзды видны на входе, «Главной» и в голосовом.

## Поверхности, радиусы, тени

- Радиусы: `--r-xs 4` · `--r-sm 6` · `--r-md 10` · `--r-lg 14` · `--r-xl 18` · `--r-2xl 24` · `--r-pill`.
- Тени подкрашены в синий: `--shadow-sm/md/lg`; `--shadow-lg` с тонким бликом сверху.
- «Стекло» — `--glass` + `--glass-sheen` (+ `backdrop-filter: blur(var(--glass-blur))`) только на маленьких
  элементах: карточка входа, плеер, тосты, подписи тайлов. Большие панели не размываем — размытие над
  анимированным фоном пересчитывается каждый кадр.

## Живой фон

- Туманность — фон `body` (градиенты, рисуется один раз). Звёзды — `body::before` (дальние, 512 px плитка)
  и `body::after` (ближние, 768 px, с четырёхлучевыми «иглами»). Двигаются только `transform`/`opacity`
  — это делает компоновщик, главный поток свободен.
- `<html data-cosmos="live|still">` ставит `cosmos.js`; `data-cosmos-why` — причина паузы:
  `pref` (выключено «Анимированный фон»), `motion` (уменьшение движения), `hidden` (вкладка скрыта / окно свёрнуто),
  `blur` (окно не в фокусе — важно для игр в Electron), `media` (в голосовом идёт трансляция/камера,
  играет видео, полноэкранный режим), `voice` (вы подключены к голосовому каналу — звонок часто идёт
  вместе с игрой), `theme` (светлая тема). При открытой модалке фон замирает средствами CSS.
- До загрузки JS фон стоит (кадр не двигается) — первая отрисовка ничего не ждёт.

## Движение

- Длительности `--dur-fast 120` · `--dur 180` · `--dur-slow 280`, кривые `--ease`, `--ease-out`, `--ease-spring`.
- Модалки появляются с подъёмом и масштабом, сообщения — снизу, смена канала — короткий
  fade/slide (Web Animations API), голосовые тайлы говорящего — мягкое «дыхание» свечения (opacity).
- «Уменьшение движения» (система или настройка) обнуляет длительности и останавливает декоративные циклы:
  фон, вращение рамок, свечения.

## Профили 2.0

- Рамки аватара: `orbit`, `nova`, `comet`, `aurora`, `eclipse`, `constellation` — `data-frame` на `.avatar`,
  рисуются `::after` (SVG, на 10 % больше аватара). В карточке профиля медленно вращаются, в списках — статичны;
  на мелких аватарах (`avatar--sm`) не показываются.
- Анимированные баннеры: `nebula`, `aurora`, `galaxy`, `sunrise`, `deep` — `.profile-banner-preset[data-preset]`,
  показываются, если не загружена своя картинка баннера.
- Значки (автоматические, выдаёт сервер, вручную задать нельзя): «Основатель» (владелец сервера; на сервере —
  только владелец этого сервера), «Ветеран» (аккаунту ≥ 30 дней), «Меломан» (добавил в библиотеку бота ≥ 5 треков),
  «Стример» (хоть раз показывал экран), «Бот».

## Темы серверов

- `server.theme = { accent: '#rrggbb' | null, background: 'nebula' | 'aurora' | 'galaxy' | 'eclipse' | 'deep' | null }`,
  меняет участник с правом «Управлять сервером» (Настройки сервера → «Оформление»), рассылается `server:updated`.
- Пока открыт сервер: `<html style="--accent" data-server-accent data-server-bg>`; производные акцента считает CSS
  (`color-mix`), цвет текста на акценте — JS по контрасту (белый или тёмный).

## Правила

- Пользовательский текст — только через `textContent` (как во всём клиенте).
- Новые цвета — через токены; жёсткие `rgba(106, 69, 255, …)` не добавлять (не поменяются с акцентом сервера).
- Фокус всегда видим: контур `--accent-text` + мягкое свечение.
- 375 px: никакой горизонтальной прокрутки (проверяет `tests/v17-redesign.spec.js`).
