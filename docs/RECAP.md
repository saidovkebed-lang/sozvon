# «Astra Итоги»

Итоги сервера за месяц или год в духе Spotify Wrapped: полноэкранные слайды с крупными цифрами,
наградами и топом треков, плюс карточка-картинка, которой можно поделиться.

## Где открыть

- Кнопка **«Итоги»** (значок столбиков) в шапке сервера, рядом с настройками.
- Кнопка **«📊 Открыть Итоги»** под объявлением бота в чате.
- Внутри: стрелки ← → (или PageUp/PageDown, Home/End), кнопки ‹ › по краям, касание левой трети экрана —
  назад, остальное — вперёд, свайп влево/вправо. Esc закрывает. Вверху — выбор периода (месяцы, в которых
  была активность, текущий месяц и годы).
- Последний слайд — **«Поделиться»**: карточка 1080×1350 рисуется прямо в браузере (`<canvas>`),
  её можно **скачать PNG** или **отправить в текстовый канал** вложением (обычная загрузка файла,
  нужны права «Отправлять сообщения» и «Прикреплять файлы»). Там же — настройки (ниже).
- С включённой настройкой «Меньше движения» (или системной `prefers-reduced-motion`) слайды без анимаций.

## Что собирается

Только счётчики по серверу и месяцу (`ГГГГ-ММ`, время сервера). Текст сообщений, названия каналов,
содержимое вложений и любые данные личных сообщений **не сохраняются**.

| Раздел | Общие цифры сервера | Лично (для рейтингов) |
|---|---|---|
| Голос | минуты (сумма по людям), заходы, минуты по часам суток и дням, пик людей одновременно во всех голосовых каналах | минуты, самая долгая сессия, «ночные» минуты 00:00–05:00 |
| Сообщения | количество, вложений, по часам и дням | количество, вложения, «ночные» сообщения |
| Трансляции экрана | минуты, пик людей в канале во время трансляции (зрители = участники канала минус стример) | минуты трансляции |
| Музыка (DJ Бот) | проигрывания, своими руками / автоплей, минуты звучания, топ треков (название + исполнитель) и исполнителей | сколько треков поставил (по `addedBy`) |
| «Смотреть вместе» | видео, минуты, топ названий | минуты просмотра (кто был в канале), сколько видео поставил |
| Участники | новые участники по инвайту | — |

Бот не считается нигде. Реакций в Astra нет — они не собираются.

**Награды** (только среди участников сервера, которые не отказались): «Голос сервера» — больше всех минут
в голосе; «Ночная смена» — больше всех активности с 00:00 до 05:00 (минута в голосе = 1 очко, сообщение = 1 очко);
«Диджей» — больше всех поставленных треков; «Режиссёр» — дольше всех транслировал экран; «Болтун» — больше всех
сообщений; «Киноман» — больше всех смотрел вместе; «Марафонец» — самая долгая сессия в голосе.
Ещё слайды: часы вместе, самый жаркий день и час пик, топ-5 треков, кино, трансляции, новенькие и «А это ты»
(личные цифры — видны только самому человеку).

## Конфиденциальность и отказ

- Настройка **«Участвовать в Итогах»** (по умолчанию включена) — на последнем слайде, хранится в профиле
  (`user.recapOptOut`).
- **Выключили** — личные записи удаляются сразу из всех месяцев всех серверов; дальше ваша активность
  попадает **только в обезличенные суммы** сервера (например, «9,6 ч вместе», «120 сообщений»), без имени
  и без личного счётчика. В наградах, рейтингах и на карточке вас нет.
- **Включили снова** — считаем с этого момента; удалённое прошлое не возвращается.
- Личные сообщения (ЛС) не учитываются вообще: статистика собирается из событий, которые сервер рассылает
  участникам каналов серверов, а ЛС идут другим путём.
- Итоги видят только участники сервера; в рейтингах — только текущие участники.

## Хранение

- Файл `data/stats.json` — отдельно от `data/db.json`, чтобы не переписывать базу каждую секунду.
  Пишется атомарно (tmp + rename) **раз в минуту** и при выключении сервера; идущие голосовые сессии
  зачитываются при каждой записи (если сервер упадёт — потеряется максимум минута).
- **Хранится 24 месяца**: более старые месяцы и данные удалённых серверов удаляются автоматически.
- Объём — несколько килобайт на сервер в месяц (уникальных треков/видео в месяце — до 1000).
- В резервные копии (`deploy/backup.sh`) файл попадает вместе со всей папкой `data/`.

## Объявления

1-го числа (не раньше 10:00 по времени сервера; если сервер был выключен — при первой проверке позже) бот пишет
в первый текстовый канал сервера «📊 Итоги <месяца> готовы — открыть» с кнопкой. В первую неделю января —
ещё и «📊 Итоги <года> года готовы — открыть». Проверка — каждые 5 минут; объявляются только периоды, в
которых была активность, и каждый — один раз (последний объявленный месяц/год хранится в `stats.json`).
Выключить объявления может участник с правом «Управлять сервером»: переключатель «Объявлять Итоги в чате».

## API

- `GET /api/servers/:sid/recap?period=2026-10|2026` — итоги (только участникам; бот — 403, не участник — 404,
  неверный период — 400). Без `period` — текущий месяц. Ответ:
  `{period, kind: 'month'|'year', label, server, empty, available: {months, years}, totals: {voiceMinutes,
  voiceHours, sessions, messages, attachments, streamMinutes, streamViewersPeak, peakUsers, peakAt, newMembers,
  music: {plays, manual, autoplay, minutes}, watch: {videos, minutes}}, busiestDay, busiestHour, hours[24],
  topTracks, topArtists, topVideos, awards: [{id, title, caption, unit, user, value}], leaderboards: {voice,
  messages, tracks}, me: {participate, stats, user}, settings: {announce, canManage}, generatedAt}`.
  Кэш: общая часть — в памяти до 15 с, `Cache-Control: private, max-age=15`.
- `PUT /api/servers/:sid/recap/settings {announce: boolean}` — право «Управлять сервером».
- `GET|PUT /api/me/recap {participate: boolean}` — своё участие.
- Сообщение-объявление несёт поле `recap: {serverId, period}`.

## Код и тесты

- Сервер: `server/stats.js` (сбор, хранение, итоги, объявления, API). Подключение — одна строка в
  `emitToViewers` (`server/realtime.js`): голос (`voice:members`), музыка (`music:state`), «Смотреть вместе»
  (`watch:state`), сообщения (`message:new`); плюс `server:join` (новые участники).
- Клиент: `public/js/ui/recap.js`, стили `public/css/recap.css`.
- Тест: `tests/v18-recap.spec.js` на музыкальном стенде. Стенд запускается с `SOZVON_TEST_HOOKS=1`, что
  включает `POST /api/__test/stats {now, flush, announce}` — подмена часов статистики (в бою этого маршрута нет).

## Ограничения

- «Зрители» трансляции — участники того же голосового канала (кто реально открыл трансляцию, не учитывается).
- «Киноман» засчитывает время всем, кто был в канале, пока видео играло (даже если вкладка была свернута).
- Время — по часовому поясу сервера (`TZ`), а не каждого участника.
- Один и тот же трек подряд с тем же `qid` считается одним проигрыванием.
