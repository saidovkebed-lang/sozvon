# Telegram-бот Astra

У каждого сервера Astra может быть свой Telegram-бот (его создаёт владелец сервера — см. «Настройка» ниже).
Через него можно:

- получать в Telegram **личные сообщения и упоминания**, пока вас нет в Astra, и **отвечать прямо из Telegram**;
- **входить без пароля** — кнопкой «✅ Войти» в боте;
- **сбросить забытый пароль** по одноразовой ссылке;
- получить **ссылку-приглашение** на свой сервер, чтобы переслать другу;
- получать коды входа и подтверждать вход кнопкой «Это я» (двухфакторная защита — [SECURITY.md](SECURITY.md#вход-через-telegram)).

## Привязка

1. Astra → «Настройки» → «Моя учётная запись» → «Двухфакторная защита» → «Telegram» (или «Настройки» →
   «Уведомления» → «Telegram» → «Привязать Telegram»).
2. Введите текущий пароль. Галочка **«Вход без пароля через Telegram»** включена по умолчанию — снимите её,
   если хотите входить только с паролем.
3. Откройте ссылку (или QR-код) и нажмите в боте «Start». Бот ответит «Аккаунт Astra … привязан» и покажет меню.

Совет: включите в Telegram «Облачный пароль» (Настройки → Конфиденциальность), чтобы ваш Telegram нельзя было
перехватить через SIM-карту.

## Меню бота

Команда **/menu** (или кнопка «☰ Меню» рядом с полем ввода) открывает меню. Кнопки меняют то же сообщение,
«‹ Назад» возвращает на шаг назад.

| Кнопка | Что делает |
|---|---|
| 💬 Уведомления | что пересылать в Telegram, пауза на 1 или 8 часов |
| 🔐 Безопасность | сбросить пароль, выйти на всех устройствах, выключить вход без пароля, отвязать Telegram |
| 🎟 Пригласить друга | выбрать сервер и получить ссылку-приглашение с кнопкой «📤 Поделиться» |
| 🌐 Открыть Astra | открыть сайт сервера |
| ❓ Помощь | краткая справка |

Если аккаунт ещё не привязан, бот на `/start` подскажет, как это сделать.

## Уведомления и ответы

Бот присылает:

- **💬 личные сообщения** — «Личные сообщения · автор» и текст;
- **🔔 упоминания** `@ваш_ник` — «Сервер · #канал», кто упомянул и текст;
- **@everyone и @here** — выключены по умолчанию, включаются в настройках.

Вложения не пересылаются — в сообщении будет пометка «📎 Вложение: фото/файл — откройте Astra».

**Когда приходят:** по умолчанию — только когда вас нет в Astra (нет открытой вкладки или окна на экране),
как push-уведомления. В статусе **«Не беспокоить»** и на паузе уведомления не приходят.

**Как ответить:** ответьте (reply) на уведомление в Telegram — или нажмите «↩️ Ответить» и напишите следующее
сообщение. Ответ уйдёт в тот же канал или ЛС от вашего имени — с теми же правами и ограничениями, что в Astra
(например, в канал, где вам нельзя писать, ответ не уйдёт, и бот скажет почему). Можно отправлять только текст;
`/cancel` отменяет ответ.

**Настройки** — в боте («💬 Уведомления») или в Astra: «Настройки» → «Уведомления» → «Telegram»:
личные сообщения, упоминания, @everyone, «только когда меня нет в Astra», пауза.

## Вход без пароля

1. На экране входа нажмите **«Войти через Telegram»** и введите имя пользователя.
2. Бот пришлёт «🔐 Вход в Astra без пароля» с устройством и примерным адресом — нажмите **«✅ Войти»**.
   Astra войдёт сама.
3. Если у вас включено приложение-аутентификатор, после «✅ Войти» нужно ввести код из него (так одного
   Telegram мало, чтобы войти).

Не вы? Нажмите «⛔ Это не я» — запрос отменится, вход через Telegram приостановится на 15 минут.

Вход без пароля работает, только если он включён. **Включить** его можно только в Astra («Уведомления» →
«Telegram» → «Вход без пароля через Telegram», с вводом пароля); **выключить** — и там, и в боте
(«🔐 Безопасность»).

## Забыли пароль

1. На экране входа нажмите **«Забыли пароль?»** и введите имя пользователя (или в боте: «🔐 Безопасность» →
   «🔑 Сбросить пароль»).
2. Если к аккаунту привязан Telegram, бот пришлёт кнопку **«🔑 Сброс пароля»** — ссылка действует 15 минут
   и срабатывает один раз.
3. Придумайте новый пароль. Если включено приложение-аутентификатор, понадобится ещё код из него или код
   восстановления.
4. После смены пароля **все сеансы** на всех устройствах завершаются — войдите заново.

Страница входа отвечает одинаково для любого имени — по ней нельзя узнать, есть ли такой пользователь.
Telegram не привязан — попросите владельца сервера сбросить пароль.

Если ссылку вы не запрашивали, нажмите «⛔ Это не я» — она перестанет работать, пароль останется прежним.

## Безопасность

- **Выйти на всех устройствах** — «🔐 Безопасность» → «📱 Выйти на всех устройствах» (с подтверждением).
- **Отвязать Telegram** — в Astra («Двухфакторная защита» → «Отвязать»: пароль и код) или в боте:
  «⛔ Отвязать Telegram» и затем код восстановления или код из приложения-аутентификатора (бот сразу удалит
  сообщение с кодом). Одного доступа к чату для отвязки мало.
- Бот принимает кнопки только из привязанного личного чата; пересланные сообщения и чужие чаты не сработают.
- Подробности и ограничения — [SECURITY.md](SECURITY.md#сброс-пароля-и-вход-без-пароля-через-telegram).

## Настройка (владелец сервера)

1. Создайте бота в @BotFather (`/newbot`) и получите токен. Можно использовать того же бота, что для резервных
   копий (`sudo bash /opt/sozvon/deploy/backup.sh setup`).
2. В `/etc/sozvon.env`: `TELEGRAM_BOT_TOKEN=…` (если не задан — берётся `ALERT_TELEGRAM_TOKEN`, затем
   `BACKUP_TELEGRAM_TOKEN`) и публичный адрес `PUBLIC_URL=https://…` (его ставит `install.sh`; без него в
   сообщениях не будет ссылок — сброс пароля и кнопки «Открыть»).
3. `sudo systemctl restart sozvon`.

Telegram из России бывает недоступен напрямую — тогда бот ходит через VPN-прокси (`SPOTIFY_PROXY`,
`deploy/vpn-proxy.sh`) или `TELEGRAM_PROXY`. Сервер сам постоянно получает сообщения бота (вебхук не нужен);
`backup.sh setup` при работающем сервере узнаёт chat id у сервера, а не у Telegram. Цветные кнопки
используются, если их поддерживает Bot API (иначе — обычные); выключить — `TELEGRAM_BUTTON_STYLE=0`.
