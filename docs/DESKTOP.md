# Astra для ПК

Отдельное приложение «Astra» для Windows (и Linux). Внутри тот же Astra, что и в браузере,
но с тем, чего браузер не умеет:

- **рация работает в любой программе.** Клавиша «нажми и говори» срабатывает, даже когда вы в игре
  или в другом окне. Сочетания «выключить микрофон» и «выключить звук» тоже работают глобально;
- **значок в трее** (возле часов): микрофон и звук можно выключить прямо оттуда, а при закрытии окна
  приложение не выходит, а прячется в трей;
- **автозапуск** при входе в Windows (по желанию);
- **демонстрация экрана**: можно выбрать конкретный экран или окно, у каждого есть превью.
  На Windows передаётся и звук компьютера;
- **уведомления Windows** и красный счётчик непрочитанных на значке в панели задач.

## Скачать

Откройте свой сервер Astra в браузере и нажмите «Скачать приложение для ПК» (кнопка есть на экране входа
и в «Настройки → О приложении»), или сразу перейдите по адресу `https://<ваш сервер>/download`,
например <https://89-108-81-153.sslip.io/download>. Файлы раздаёт сам сервер, поэтому GitHub
для скачивания не нужен.

| Файл | Для чего |
|------|----------|
| `Sozvon-Setup-<версия>.exe` | **Установщик для Windows 10/11 (64-бит). Подходит почти всем.** |
| `Sozvon-<версия>-win-x64.zip` | Портативная версия для Windows: распакуйте в папку и запустите `Sozvon.exe`, установка не нужна |
| `Sozvon-<версия>-x86_64.AppImage` | Linux (x64) |

Версии для macOS пока нет. Пользуйтесь Astra в Safari или Chrome.

## Установка на Windows

1. Запустите `Sozvon-Setup-<версия>.exe`.
2. **Windows может показать синее окно «Windows защитила ваш компьютер» (SmartScreen).**
   Так бывает потому, что у приложения нет платной цифровой подписи, а не потому, что в нём вирус.
   Нажмите **«Подробнее»**, затем **«Выполнить в любом случае»**.
   Если браузер пишет при скачивании «файл обычно не скачивают», выберите «Сохранить» → «Всё равно сохранить».
3. Выберите папку (можно оставить как есть) и нажмите «Установить». Права администратора не нужны,
   приложение ставится только для вашего пользователя.
4. На рабочем столе и в меню «Пуск» появится ярлык «Astra».

Удаляется как обычная программа: «Параметры → Приложения → Astra → Удалить». Настройки и вход
лежат в `%APPDATA%\Sozvon` и при удалении остаются. Если хотите стереть всё, удалите эту папку.

**Linux:** `chmod +x Sozvon-*.AppImage && ./Sozvon-*.AppImage`. Если AppImage не запускается,
установите пакет `libfuse2`. Глобальная рация работает только в сеансе X11, под Wayland она не сработает.

## Первый запуск

При первом запуске приложение спросит **адрес сервера**. Там уже вписан общий сервер
`https://89-108-81-153.sslip.io`. Если вас позвали друзья со своим сервером, вставьте их адрес.
Нажмите «Проверить», затем «Подключиться». После этого войдите как обычно.

Сменить сервер можно в любой момент: значок в трее → «Сервер…» (или меню окна: нажмите **Alt**,
затем «Astra → Сервер…»).

**Если сервер домашний и сертификат у него самодельный**, приложение покажет предупреждение
«Сертификат не подтверждён» и отпечаток сертификата. Поставьте галочку «Я доверяю этому серверу» только
в том случае, если это ваш сервер или сервер друзей и адрес вы знаете точно. Доверие выдаётся одному адресу
и одному сертификату. Остальным сайтам с плохими сертификатами приложение по-прежнему не доверяет.

Доступ к микрофону, камере и уведомлениям приложение выдаёт **только своему серверу**, без
лишних вопросов. Ссылки на другие сайты открываются в обычном браузере.

## Глобальная рация (push-to-talk)

1. «Настройки → Голос и видео → Режим ввода: **Рация**».
2. Там же назначьте клавишу. По умолчанию это `V`. Подойдут и `CapsLock`, `F`-клавиши, боковые
   клавиши цифрового блока и т. п.
3. Готово. Клавиша работает, даже когда Astra свёрнут или вы в игре.

Сочетания «Вкл/выкл микрофон» (`Ctrl+Shift+M`) и «Вкл/выкл звук» (`Ctrl+Shift+D`) из раздела
«Горячие клавиши» тоже работают глобально.

> Игра, запущенная **от имени администратора**, не пропускает к приложению нажатия клавиш, это ограничение Windows.
> В таком случае запустите Astra тоже от имени администратора (правой кнопкой по ярлыку).

## Трей

Значок Astra появляется возле часов (если его не видно, нажмите на стрелку `^`).
- Щелчок открывает окно Astra (или прячет его).
- Правая кнопка открывает меню: «Показать», «Выключить микрофон», «Выключить звук», «Сервер…»,
  «Запускать при входе в систему», «Сворачивать в трей при закрытии», «О приложении», «Выход».
- Красная точка на значке означает непрочитанные сообщения, красный перечёркнутый кружок означает, что выключен микрофон,
  жёлтый — что выключен звук.

Когда «Сворачивать в трей при закрытии» включено (так по умолчанию), крестик окна прячет Astra
в трей, и вы остаётесь в голосовом канале. Совсем выйти можно через трей → «Выход» или `Ctrl+Q`.

## Автозапуск

Трей → отметьте «Запускать при входе в систему». Astra будет запускаться сразу свёрнутым в трей.

## Демонстрация экрана

Нажмите «Демонстрация экрана», выберите качество, затем экран или окно в списке с превью.
Звук компьютера передаётся на Windows, если включить «Звук экрана». На Linux звук экрана не передаётся.

На **Windows 11** звук компьютера захватывает `sozvon-capture.exe` **без звука самой Astra** (WASAPI
process loopback, как в Discord и OBS): голоса звонка и музыка бота в трансляцию не попадают, поэтому звук
игры или видео идёт ровно, даже когда в голосовом говорят.

На **Windows 10** такой возможности нет: Windows отдаёт звук компьютера целиком — вместе с голосами звонка.
Чтобы зрители не слышали каждого говорящего второй раз с задержкой трансляции («эхо», «церковный хор»),
пока в звонке кто-то говорит, звук экрана там приглушается примерно на 26 дБ и возвращается через ~0,4 с
после паузы. Чтобы звук игры не проседал, на Windows 10 показывайте отдельное окно игры или обновитесь до Windows 11.

На Windows экран снимает штатный захват Chromium (Windows Graphics Capture от Microsoft) — как в браузере
и Discord. Минус: в играх со своим курсором (Noita и др.) курсор может не попадать в трансляцию.

Для таких игр в трее есть галочка «Свой захват экрана (курсор в играх вроде Noita)»: экран тогда снимает
своя программа `sozvon-capture.exe` (DXGI Desktop Duplication, как «Захват экрана» в OBS) и дорисовывает
курсор сама. Пока трансляцию никто не смотрит, захват стоит на паузе. При выборе окна снимается его область
на экране: окна, перекрывающие игру, тоже попадут в трансляцию. Действует со следующей демонстрации.

В браузере (не в приложении) захват делает сам браузер — для игр показывайте экран из приложения для ПК.

## «Слушает Spotify» — что играет на компьютере (Windows)

Как в Discord: если на компьютере играет музыка, друзья видят в списке участников строку
«🎵 Spotify: Исполнитель — Название», а в вашем профиле — карточку «Слушает Spotify» с обложкой, названием,
исполнителем, альбомом и полосой прогресса, кнопками «Найти на YouTube» и «Включить в Astra» (добавить трек
в очередь DJ Бота в голосовом канале зрителя — нужно право управлять музыкой).

Astra берёт данные там же, где их показывает регулятор громкости Windows 10/11 (системные медиасессии):
Spotify, Яндекс Музыка, VK Музыка, Apple Music / iTunes, AIMP, foobar2000, MusicBee, Winamp, VLC,
«Медиаплеер» Windows, Telegram, Звук, Deezer, TIDAL, SoundCloud, YouTube Music (как приложение) и любые другие
программы, которые сообщают Windows, что играют. Если плеер Windows ничего не сообщает (так бывает у старых
плееров и некоторых плагинов), Astra его тоже не увидит.

- **Пауза или остановка** — строка пропадает. Когда музыка играет у вас самой Astra (DJ Бот в голосовом канале),
  показывается «Сейчас слушает» бота.
- **Настройки** — «Настройки → Профиль → Конфиденциальность»: «Показывать, что я слушаю» выключает всё сразу
  (программа слежения при этом не запускается); «Учитывать браузеры» (по умолчанию выключено: сайт браузер
  Windows не называет, в статусе было бы «Chrome»); «Источники» — что сейчас сообщает Windows, с галочками.
- Видно тем, с кем у вас общий сервер или личная переписка. Сервер ничего не сохраняет: данные живут в памяти,
  пока вы в сети, и пропадают через 10 минут без обновлений. Обложку сервер находит сам (Deezer/iTunes, как у бота).
- Работает на Windows 10 (1809+) и 11, только в приложении для ПК (в браузере Windows такие данные не отдаёт).

## Обновление

Приложение само раз в несколько часов спрашивает у сервера, не вышла ли новая версия. Если вышла,
появится уведомление «Доступно обновление», а в меню трея пункт «Скачать версию …». Скачайте
новый `Sozvon-Setup-…exe` и запустите его поверх старой версии: настройки и вход сохранятся.
Проверить вручную можно так: нажмите Alt, затем «Astra → Проверить обновления».

## Если что-то не работает

- **Белый экран или «Нет связи с сервером».** Проверьте интернет. Приложение само повторяет попытку
  каждые 15 секунд, на том же экране есть кнопка «Сервер…».
- **Нет микрофона.** «Параметры Windows → Конфиденциальность → Микрофон → Разрешить классическим
  приложениям доступ к микрофону».
- **Перезагрузить страницу** можно клавишей `F5` или `Ctrl+R`.
- **Сбросить все настройки приложения.** Выйдите из Astra и удалите папку `%APPDATA%\Sozvon`.

# Для владельца: сборка и релиз

Исходники приложения лежат в `desktop/`. Это Electron 44.8.0, сборщик electron-builder 26.15.3, глобальные
клавиши даёт `uiohook-napi` 1.5.5 (готовые N-API-бинарники для win32-x64 и linux-x64, компилятор
не нужен). Своей сборки фронтенда у приложения нет: окно открывает веб-клиент с сервера, поэтому
обновления интерфейса приходят вместе с `deploy/update.sh`, и пересобирать приложение для них не нужно.

```
desktop/
  package.json          версии закреплены; конфиг electron-builder в поле "build"
  src/main.js           главный процесс: окно, трей, меню, uiohook, разрешения, демонстрация экрана
  src/preload.js        мост window.sozvonDesktop (contextIsolation, sandbox)
  src/keymap.js         KeyboardEvent.code / 'Ctrl+Shift+M' → коды uiohook
  src/setup.html, src/offline.html, src/ui/   окно «Сервер…» и экран «Нет связи»
  src/setup-preload.js  мост окна «Сервер…»
  src/assets/           иконка окна, трея, бейджи (генерируются)
  build/                icon.ico / icon.icns / icons/*.png (генерируются)
  scripts/make-icons.mjs  иконки из public/assets/logo.svg (npm run icons)
  scripts/smoke.mjs       smoke-тест под xvfb
  RELEASE_NOTES.md      описание релиза
```

### Сборка

На Windows (проще всего):
```
cd desktop
npm ci
npm run dist:win       # → dist/Sozvon-Setup-<ver>.exe и dist/Sozvon-<ver>-win-x64.zip
```

На Linux (так собирались релизы):
```
sudo apt install wine wine64 xvfb p7zip-full   # wine нужен NSIS-установщику для Windows
cd desktop
npm ci
npm run dist           # Windows (exe+zip) и Linux AppImage
npm run dist:linux     # только AppImage
```
Через прокси: `ELECTRON_GET_USE_PROXY=1 GLOBAL_AGENT_HTTPS_PROXY=$HTTPS_PROXY npm run dist`.
Перед новой версией поменяйте `"version"` в `desktop/package.json`. Иконки перегенерирует `npm run icons`
(они уже лежат в репозитории, запускать нужно только после смены логотипа).
Собрать macOS на Linux или Windows нельзя: нужен Mac (`npx electron-builder --mac`), подпись и
нотаризация Apple. Конфиг `mac` в package.json есть, но такую сборку не проверяли.

### Проверка

```
# сервер для теста
DATA_DIR=/tmp/szv PORT=3850 HTTPS=0 node server/index.js &
cd desktop
xvfb-run -a node scripts/smoke.mjs dist/linux-unpacked/sozvon --server=http://localhost:3850
# → isDesktop:true, список экранов, getDisplayMedia, глобальная рация [true,false], «SMOKE OK»
```
Параметры запуска для тестов: `--server=URL` (или `SOZVON_SERVER_URL`), `--user-data-dir=ПУТЬ`,
`--hidden` (запуск свёрнутым в трей), `SOZVON_ALLOW_INSECURE_LOCALHOST=1` (самоподписанный сертификат
только для localhost/127.0.0.1). Под root нужен `--no-sandbox`.

### Публикация релиза

1. Соберите, затем проверьте `dist/SHA256SUMS.txt` (`cd dist && sha256sum Sozvon-* > SHA256SUMS.txt`).
2. Создайте релиз GitHub с тегом **`desktop-v<версия>`** (например `desktop-v1.0.0`) и текстом из
   `desktop/RELEASE_NOTES.md`, приложите файлы:
   - `Sozvon-Setup-<ver>.exe`
   - `Sozvon-<ver>-win-x64.zip`
   - `Sozvon-<ver>-x86_64.AppImage`
   - `SHA256SUMS.txt`

   Пример: `gh release create desktop-v1.0.0 desktop/dist/Sozvon-Setup-1.0.0.exe desktop/dist/Sozvon-1.0.0-win-x64.zip desktop/dist/Sozvon-1.0.0-x86_64.AppImage desktop/dist/SHA256SUMS.txt -t "Astra для ПК 1.0.0" -F desktop/RELEASE_NOTES.md`
3. На сервере запустите `deploy/update.sh`. Он заберёт последний релиз `desktop-v*` в `DATA_DIR/downloads/`
   и запишет `app-release.json`, после чего страница `/download` и `GET /api/app/latest` начнут отдавать
   новые файлы, а установленные приложения покажут уведомление об обновлении.

Файлы сборки (`desktop/dist/`) и `desktop/node_modules/` в git не коммитятся (`desktop/.gitignore`).

### Подпись кода

Приложение не подписано, поэтому SmartScreen при первом запуске показывает предупреждение (как его обойти, описано выше).
Убрать предупреждение может только сертификат подписи кода (OV/EV). Когда он появится, задайте
`CSC_LINK`/`CSC_KEY_PASSWORD` (или `win.signtoolOptions`) и пересоберите.

### Мост `window.sozvonDesktop` (для разработчиков клиента)

Мост доступен только странице своего сервера. Все методы не бросают исключений.

| Член | Описание |
|------|----------|
| `isDesktop: true`, `version: '1.0.0'`, `platform: 'win32'\|'linux'\|'darwin'` | признак и версия приложения |
| `onPttChange(cb(pressed:boolean)) → off()` | глобальная клавиша рации; срабатывает только когда окно **не** в фокусе (в фокусе клавишу обрабатывает сама страница) |
| `onToggleMute(cb) → off()`, `onToggleDeafen(cb) → off()` | глобальные сочетания (вне фокуса) и пункты трея |
| `setSettings({pttEnabled, pttKey, toggleMute, toggleDeafen})` | `pttKey` в формате `KeyboardEvent.code`, сочетания в формате `'Ctrl+Shift+M'` из `ui/keybinds.js`; можно передавать не все поля |
| `setVoiceState({inVoice, muted, deafened})` | для значка и галочек в трее |
| `setBadge(n)` | число непрочитанных: на Windows это оверлей на панели задач и мигание кнопки, на Linux — `app.setBadgeCount` |
| `focusWindow()` | показать окно (например из `Notification.onclick`) |
| `getScreenSources({types?, thumbnailWidth?, thumbnailHeight?}) → Promise<[{id, name, type:'screen'\|'window', thumbnail:dataURL, appIcon:dataURL\|null, displayId}]>` | источники для окна выбора |
| `selectScreenSource(id, {audio}) → Promise<boolean>` | выбрать источник, затем сразу вызвать `getDisplayMedia()`; выбор действует 15 с. Без выбора отдаётся основной экран |
| `nativeCapture: boolean` | есть своя программа захвата (Windows) |
| `startNativeCapture({sourceId, maxWidth, maxHeight, fps}) → Promise<{ok, token, url}>` | запустить свой захват; кадры I420 (заголовок 24 байта `SZC1`, см. `desktop/native/capture/capture.cpp`) читать `fetch(url)` |
| `nativeCaptureControl(token, 'pause'\|'resume'\|'update'\|'stop', params?) → Promise<{ok, url?}>` | управление; после `update` — новый `url` |
| `onNativeCaptureEnded(cb) → off()` | захват завершился сам: `{token, reason:'window-closed'\|'exit'}` |
| `openServerSettings()` | открыть окно «Сервер…» |
| `mediaWatch: boolean` | есть слежение «что играет» (Windows + `sozvon-capture.exe`) |
| `setMediaWatch(on)` | запустить/остановить помощник `sozvon-capture.exe --media` (упал — перезапуск с паузой 1…60 с; «медиасессии недоступны» трижды подряд — остановка) |
| `onMedia(cb(sessions)) → off()` | медиасессии Windows при каждом изменении (и раз в 5 с, пока играет): `[{app, title, artist, album, albumArtist, durationMs, positionMs, updatedAt, playing, current}]`; что показывать — решает страница (`public/js/media-sources.js`, `public/js/now-playing.js`) |

Приложение добавляет к User-Agent строку `SozvonDesktop/<версия>`.

### «Что играет»: протокол и проверка

`sozvon-capture.exe --media` (C++/WinRT, `GlobalSystemMediaTransportControlsSessionManager`) печатает `READY`, затем
строку JSON (UTF-8) на каждое изменение и раз в 5 с, пока что-то играет:
`{"t":"media","sessions":[{"app":"Spotify.exe","title":…,"artist":…,"album":…,"albumArtist":…,"durationMs":…,"positionMs":…,"updatedAt":<unix мс>,"playing":true,"current":true}]}`
(`positionMs` — на момент `updatedAt`; 0 — неизвестно). Опрос раз в секунду; «умерший» менеджер сессий (перезапуск
проводника, выход из сна) запрашивается заново. Конец stdin — выход с кодом 0; медиасессии недоступны — код 4.
Сборка — `cl … /std:c++20 …` (C++/WinRT нужны корутины C++20), `windowsapp.lib` подключается через `#pragma comment`.

Проверка без релиза: workflow `native-check` (вручную или пуш в ветку `native-*`) собирает `sozvon-capture.exe`
той же строкой, что и релиз, и запускает `desktop/scripts/capture-smoke.cjs` на `windows-latest` (в том числе
`--media` со своей медиасессией из PowerShell — проверка кириллицы и экранирования). Тесты на Linux —
`tests/v22-now-playing.spec.js` (подделка помощника `tests/fixtures/fake-capture.cjs --media`,

### Рация и игры с античитом

Клавиша рации на Windows отслеживается через Raw Input (программа `sozvon-capture.exe --keys`), как в Discord:
Astra только узнаёт о нажатии нужной клавиши и не стоит на пути ввода игры. Системный перехватчик клавиатуры и
мыши (uiohook) больше не используется на Windows — он пропускал через приложение каждое движение мыши, и
соревновательные игры с античитом ядра (Valorant, CS2) могли зависать. На Linux рация работает как раньше.
